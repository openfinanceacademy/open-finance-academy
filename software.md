# Software

Explore the technology used to move money, connect financial data, run finance teams, research markets, and build financial products. This directory focuses on software, developer platforms, and infrastructure. For institutions and account providers, see [Banks]({{ '/banks/' | relative_url }}) and [Brokerages]({{ '/brokerages/' | relative_url }}).

The selection covers established commercial products and notable open source projects across the main areas of financial technology. It is a broad starting point, not an exhaustive inventory or a ranking. Each product link points to its official website, documentation, or source repository and supports the accompanying description. Regional availability and supported integrations vary by product.

*Directory updated: September 13, 2026.*

## Payment networks and integration standards

These are related infrastructure references rather than standalone software products. They cover the networks, payment schemes, and message formats that financial software connects to. The links lead to operators or standards organizations; production access depends on the relevant participation arrangements.

| Network, scheme, or standard | Role in financial technology |
| --- | --- |
| [ACH / FedACH](https://www.frbservices.org/financial-services/ach) | US bank-payment processing used for payroll, bill payments, and other transfers; FedACH is a Federal Reserve ACH service. |
| [FedNow](https://frbservices.org/resources/financial-services/fednow) | Federal Reserve infrastructure for instant payments between participating US financial institutions. |
| [RTP network](https://www.theclearinghouse.org/payment-systems/rtp/document-library) | The Clearing House's US instant-payment network, with technical specifications for participating institutions. |
| [SEPA Instant Credit Transfer](https://www.europeanpaymentscouncil.eu/what-we-do/epc-payment-schemes/sepa-instant-credit-transfer/sepa-instant-credit-transfer-rulebook) | A European Payments Council scheme and implementation rules for instant euro transfers. |
| [Faster Payment System](https://www.wearepay.uk/) | Pay.UK's infrastructure for real-time payments between UK accounts. |
| [Pix](https://www.bcb.gov.br/en/financialstability/pixfaqen/1000) | Brazil's instant-payment system, developed by its central bank. |
| [Unified Payments Interface (UPI)](https://www.npci.org.in/product/upi/about-upi) | NPCI's system for initiating instant bank payments through applications in India. |
| [New Payments Platform (NPP)](https://www.auspayplus.com.au/solutions/nppa-capabilities) | Australian account-to-account payment infrastructure supporting real-time payments and related services. |
| [Swift](https://www.swift.com/about-us/who-we-are/what-swift) | A secure financial messaging network used to exchange payment instructions; banks and payment systems perform the money transfer. |
| [Visa Developer](https://developer.visa.com/) and [Mastercard Developers](https://developer.mastercard.com/) | Integration resources for card-network services, payments, and related data products. |
| [ISO 20022](https://www.iso20022.org/) | A financial-message standard used by many payment and reporting systems. |
| [FIX Trading Community](https://www.fixtrading.org/standards/) | Standards for exchanging electronic trading and related financial messages. |
| [FINOS FDC3](https://fdc3.finos.org/) | A standard for letting financial desktop applications share context and work together. |
